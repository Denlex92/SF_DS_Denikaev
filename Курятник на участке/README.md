# Проблематика фермерского хозяйства
Современные фермерские хозяйства сталкиваются с постоянной угрозой со стороны диких хищников. Волки, лисы, куницы и хорьки ежегодно наносят значительный ущерб, уничтожая домашнюю птицу. Существующие методы защиты часто оказываются недостаточно эффективными.

Ключевые проблемы:

Отсутствие круглосуточного мониторинга территории

Запаздывающая реакция на угрозу

Неэффективность стандартных отпугивателей

Отсутствие дифференцированного подхода к разным видам хищников

# Технологическое решение
# ChickenGuard - это интеллектуальная система компьютерного зрения, которая автоматически обнаруживает хищников и активирует целенаправленную защиту. Система использует современные нейросетевые модели для точного определения типа хищника и выбора оптимального метода отпугивания.

# Основные возможности
1. Автоматическое обнаружение хищников
4 целевых вида:волк (wolf), лиса (fox), куница (marten), хорёк (weasel)

Высокая точность: модель обучена на тысячах изображений

Круглосуточная работа: функционирует в любых условиях освещения

2. Умный отпугиватель
Каждому виду хищника соответствует своя частота ультразвука:

Хищник	Частота	Особенности

🐺 Волк	25 кГц	Низкие частоты, действуют на крупных животных

🦊 Лиса	30 кГц	Средние частоты, эффективны против лис

🐾 Куница	35 кГц	Высокие частоты, отпугивают мелких хищников

🐾 Хорёк	40 кГц	Очень высокие частоты, проникают в норы

3. Визуальный контроль
Красные рамки обнаружения

Четкие подписи видов
