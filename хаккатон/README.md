# Учебный проект «Анализ сайта»

Проект выполнен в рамках учебной задачи по анализу поведения пользователей сайта «СберАвтоподписка». Цель проекта — построить модель машинного обучения, предсказывающую вероятность совершения целевого действия в рамках пользовательской сессии на сайте.

В проекте выполнены:

- исследовательский анализ данных (EDA);
- построение и сравнение ML-моделей;
- интерпретация признаков;
- реализация скрипта предсказания и API для инференса.

## Цель проекта

Необходимо предсказать вероятность того, что пользователь совершит целевое действие на сайте: оставит заявку, закажет звонок или выполнит другое конверсионное событие. По брифу модель должна помогать оценивать эффективность каналов трафика, адаптировать рекламные кампании и улучшать пользовательский опыт сайта.[

Целевая переменная сформирована на уровне сессии по событию `sub_submit_success`, которое интерпретируется как успешная отправка заявки. Конверсия по сессиям в полученных данных составляет около 0.85%, что указывает на выраженный дисбаланс классов и делает ROC-AUC подходящей основной метрикой качества.

## Данные

В проекте используются две основные таблицы:

- `ga_sessions` — данные по сессиям: источники трафика, utm-метки, устройство, браузер, география и другие признаки уровня сессии;
- `ga_hits` — данные по событиям внутри сессии: просмотры, действия пользователя и события сайта.

Для построения модели данные были агрегированы до уровня сессии. Дополнительно были созданы поведенческие признаки, например:

- `hits_count` — число хитов в рамках сессии;
- `unique_pages` — число уникальных страниц в сессии;
- `events_count` — количество событий;
- `visit_number` — номер визита пользователя.

## Исследовательский анализ данных

В ходе EDA были проанализированы:

- структура и типы данных;
- пропуски и категориальные признаки;
- конверсия по каналам трафика (`utm_source`, `utm_medium`);
- различия по устройствам и городам;
- связь поведенческих признаков с целевым действием.

Ключевые наблюдения:

- конвертирующие сессии имеют существенно больше хитов и просмотров страниц, чем неконвертирующие;
- источники и каналы трафика заметно отличаются по уровню конверсии;
- признаки поведения пользователя на сайте оказываются наиболее информативными для модели.

## Модели

В проекте были протестированы две модели:

| Модель | ROC-AUC train | ROC-AUC test |
|--------|---------------|--------------|
| Logistic Regression | ~0.882 | ~0.866 |
| HistGradientBoostingClassifier | ~0.921 | ~0.917 |

Основной метрикой выбрана ROC-AUC, так как задача является бинарной классификацией с сильным дисбалансом классов, а в учебных материалах проекта ROC-AUC прямо рекомендована как базовая метрика оценки качества.[file:3]

Финальной моделью выбран `HistGradientBoostingClassifier`, так как он показал наилучшее качество на тестовой выборке.

## Интерпретация признаков

Для интерпретации модели была использована permutation importance. Наиболее важными оказались:

- `hits_count`;
- `unique_pages`;
- `utm_campaign`;
- `visit_number`;
- `utm_source`;
- `utm_adcontent`;
- `geo_city`.

Это позволяет сделать следующие выводы:

- глубина взаимодействия пользователя с сайтом играет ключевую роль в вероятности конверсии;
- маркетинговые признаки (кампания, источник, рекламный контент) заметно влияют на прогноз;
- география и характеристики устройства также вносят вклад в модель.

## Как запустить ноутбук

1. Откройте ноутбук `notebooks/01_eda.ipynb`.
2. Убедитесь, что пути к данным указывают на папку `data/`.
3. При необходимости переобучите модель и сохраните её в папку `models/`.

Пример сохранения модели:

```python
import joblib
from pathlib import Path

MODELS_DIR = Path.cwd().parent / "models"
MODELS_DIR.mkdir(exist_ok=True)
joblib.dump(gb_clf, MODELS_DIR / "model_histgb.pkl")
```

## Как запустить `predict.py`

Скрипт `app/predict.py` позволяет получить предсказание для одной сессии из JSON-файла.

Пример запуска из корня проекта:

```bash
python app/predict.py --input-json app/example_session.json
```

Пример ответа:

```json
{
  "probability": 0.02003011028097806,
  "threshold": 0.5,
  "label": 0
}
```

## Как запустить FastAPI

Файл `app/main.py` реализует API для предсказания вероятности конверсии.

Установка зависимостей:

```bash
pip install -r requirements-api.txt
```

Запуск сервера из корня проекта:

```bash
python -m uvicorn app.main:app --reload
```

После запуска доступны следующие endpoints:

- `GET /` — базовая информация о сервисе;
- `GET /health` — проверка статуса и загрузки модели;
- `POST /predict` — предсказание по JSON входу.

Swagger-документация будет доступна по адресу:

```text
http://127.0.0.1:8000/docs
```

## Коды ответов API

- `200 OK` — предсказание успешно выполнено;
- `422 Unprocessable Entity` — ошибка в структуре входного JSON или типах данных;
- `500 Internal Server Error` — модель не загрузилась или возникла внутренняя ошибка.
